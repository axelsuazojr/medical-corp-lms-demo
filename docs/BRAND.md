# Identidad MEDICAL CORP aplicada al demo

La interfaz usa como base el manual corporativo entregado para el proyecto.

## Paleta utilizada

- Azul principal: `#092F4C`
- Dorado: aproximación desde RGB 214/180/52: `#D6B434`
- Azul secundario: aproximación desde RGB 50/86/111: `#32566F`
- Verde secundario: aproximación desde RGB 175/193/45: `#AFC12D`

## Tipografía

- Preferencia: Segoe UI para interfaz.
- El manual también identifica Intro Regular e Intro Light. No se incluyen archivos de fuentes propietarias dentro del repositorio.

## Logo

`apps/web/public/brand/medical-corp-logo.png` y `apps/admin-api/public/brand/medical-corp-logo.png` fueron preparados a partir del material corporativo suministrado para el demo.

No rotar, deformar, recolorear ni desarmar el logo.
